# KudiGuide AI

KudiGuide AI is a voice-first financial ledger designed for small business owners, accessible via Telegram. It allows users to track their finances using simple voice commands, providing a seamless and intuitive way to manage business records.

## Features

- **Voice-First Interaction**: Record expenses and income using voice messages.
- **Telegram Integration**: Easy access through a familiar messaging platform.
- **Financial Tracking**: Automated ledgering of business transactions.
- **AI-Powered Analysis**: Intelligent processing of financial data.

## Tech Stack

- **Framework**: Next.js 14
- **Language**: JavaScript/React
- **Database/Backend**: Firebase
- **AI**: Groq SDK

## Getting Started

### Prerequisites

- Node.js (>= 18.17.0)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd KudiGuide_TG
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env.local` file in the root directory and add your credentials (refer to `.env.example` if available).

### Running Locally

```bash
npm run dev
```

The server will start at `http://localhost:3000`.
